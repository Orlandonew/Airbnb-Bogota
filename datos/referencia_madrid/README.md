# Datos de Referencia (Caso Original Madrid)

Esta carpeta aísla los datos de ejemplo del caso original de Madrid (`Material Descargable Caso1`) para que no se mezclen con los datos de **Bogotá**:

- `idealista.csv` — Precio medio de venta (€/m²) por distrito de Madrid.
- `poi_madrid.csv` — Puntos de interés turístico de Madrid.
- `mercado_inmobiliario.db` — Base de datos SQLite del caso de referencia de Madrid.

Los datos activos del proyecto (**Bogotá**) se encuentran en `datos/brutos/`.
